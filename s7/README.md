# PrimeSecure - Semana 7

Proyecto para la actividad formativa de la semana 7 del curso Desarrollo Orientado a Objetos I.

## Descripción

Simula el uso de hilos (`Thread`) para validar y almacenar números primos como "Códigos Primos" en una lista personalizada. Solo se permiten números primos, y el proceso se hace de forma concurrente.

## Archivos

- `PrimesList.java`: Lista que solo acepta primos.
- `PrimeWorker.java`: Hilo que agrega primos desde un rango.
- `Main.java`: Ejecuta los hilos y muestra resultados.
